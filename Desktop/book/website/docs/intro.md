## Getting Started

### Quick Setup

```bash
# Install ROS 2 Humble
sudo apt install ros-humble-desktop

# Install simulation tools
sudo apt install gazebo ros-humble-gazebo-*

# Clone code examples
git clone https://github.com/sarosh/physical-ai-book.git
cd physical-ai-book
```

### First Steps

1. Start with [Chapter 1: Introduction to Embodied Intelligence](./book-chapters/ch01_introduction.md)
2. Set up your workstation using [Chapter 2: The Hardware Stack](./book-chapters/ch02_hardware_stack.md)
3. Install ROS 2 following [Chapter 3: ROS 2 Fundamentals](./book-chapters/ch03_ros2_fundamentals.md)
