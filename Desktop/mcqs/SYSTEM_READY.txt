HOW TO USE:
═════════════════════════════════════════════════════════════════════════

FOR STUDENTS:

1. Open browser → http://localhost:5001
2. Enter name and email
3. Click "Start Quiz"
4. Answer 60 questions
   • Navigate using Previous/Next buttons
   • Questions numbered but NO total shown
   • Progress bar shows completion status
5. Click "Submit Quiz" on last question
6. See instant score and percentage

FOR TEACHERS/INSTRUCTORS:

1. Open browser → http://localhost:5001/results
2. View all student submissions
3. See statistics:
   • Total students
   • Average score
   • Highest score
4. View individual scores
5. Print or export results

→ cat results.csv

TROUBLESHOOTING:

Issue: Students can see total questions

Issue: Results not saving
Solution: Check if results.csv exists and is writable

Issue: JSON error
Solution: Verify questions.json is valid JSON
